# FoxsMusic Desktop 1.3.25 — тёмная тема «День рождения»

## Что изменилось

- Баннер сезона переведён на глубокую ночную палитру: графитовый, чёрно-фиолетовый фон и локальное тёплое свечение вокруг торта.
- Заголовок «С днём рождения!» получил приглушённый многоцветный градиент: пыльная роза, лаванда, мягкий бирюзовый и матовое золото. Яркость и свечение текста ограничены, чтобы он не утомлял глаза.
- Торт остаётся центральным объектом сцены.
- Для трёх свечей добавлены раздельные мягкие световые ореолы, плавное мерцание пламени и маленькие искры.
- Конфеты и конфетти падают медленнее, с лёгким боковым дрейфом и вращением.
- Уважает системную настройку уменьшения движения.
- Halloween, New Year, пользовательский фон, библиотека и мобильная версия не менялись.

## Проверки

- JavaScript syntax checks: `app.js`, `main.cjs`, `preload.cjs`.
- `npm test` — полный набор Desktop-тестов, включая профильное оформление.
