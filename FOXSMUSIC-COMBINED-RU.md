# FoxsMusic — единый проект Desktop + Android

В архиве находятся обе версии FoxsMusic. Настольная версия сохранена отдельно в корне проекта, мобильная Android-версия находится в `mobile/`.

## Структура

- `main.cjs`, `preload.cjs`, `index.html`, `styles.css`, `app.js` — настольный плеер на Electron.
- `assets/` — логотипы, иконки и изображения настольной версии.
- `tests/` — автоматические тесты настольной версии.
- `mobile/App.js` — интерфейс Android-приложения.
- `mobile/app.json` — конфигурация Expo/Android.
- `mobile/src/` — общие вспомогательные функции мобильного приложения.
- `mobile/assets/` — иконки и экран загрузки Android-приложения.
- `mobile/tests/` — автоматические тесты мобильной версии.

## Запуск Desktop

Требуется установленный Node.js и npm.

**Windows:** запустите `start.bat` или выполните в терминале:

```bash
npm install
npm start
```

**Linux:** выполните:

```bash
npm install
npm start
```

Сборка для Windows: `npm run dist:win`.

Сборка для Linux: `npm run dist:linux`.

## Запуск Android

Установите Node.js версии, соответствующей требованию `engines` в `mobile/package.json` (Node.js 22.13.0 или новее), затем:

```bash
cd mobile
npm install
npx expo start
```

Для открытия на телефоне можно использовать Expo Go, если используемые API и конфигурация совместимы с Expo Go. Для полноценной нативной сборки используется EAS:

```bash
npm run build:apk
```

Команда сборки APK требует настроенного аккаунта EAS и подключения к интернету. Настройки профилей находятся в `mobile/eas.json`.

## Проверка проекта

Из корня проекта:

```bash
npm test
```

Для мобильной версии:

```bash
cd mobile
npm test
```

Отчёт о проверках в этом архиве: `TEST-REPORT-RU.md`.

## Важное замечание

Desktop и Android объединены в одном репозитории/архиве, но это два отдельных приложения с собственными зависимостями и командами сборки. Музыкальная библиотека и пользовательские данные не синхронизируются автоматически между устройствами без отдельного серверного механизма синхронизации.
