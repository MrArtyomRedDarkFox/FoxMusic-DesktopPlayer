# FoxsMusic Desktop 1.4.3 — исправление ползунка

- Удалён самодельный pointerdown/pointermove/pointerup перехватчик, который конфликтовал со стандартным range input в Electron.
- Сохранён существующий обработчик input, который обновляет audioSettings.crossfadeSeconds, подпись и настройки.
- Удалены отдельные CSS-переопределения crossfade; ползунок наследует общий стиль .studio-control input[type=range] (дорожка 4 px, бегунок 13 px).
- Диапазон 0–8 секунд и значение по умолчанию 3 секунды не менялись.
- Добавлены регрессионные тесты на использование нативного range input и отсутствие конкурирующих pointer-обработчиков.

Проверить в Electron: клик по дорожке, перетаскивание бегунка, клавиши стрелок при фокусе, сохранение значения после перезапуска.
