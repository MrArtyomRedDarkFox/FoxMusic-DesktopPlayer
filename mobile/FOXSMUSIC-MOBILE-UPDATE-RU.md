# FoxsMusic Mobile — обновление оформления 0.1.1

- Сохранена компактная панель FOXSMUSIC ORIGINAL с текстом, эквалайзером и круглым DP-логотипом.
- Логотип в шапке остаётся DP.
- В пустом состоянии библиотеки и на экране загрузки используется механическая эмблема лисы из настольного проекта (`assets/foxsmusic-logo.png`).
- Обновлена нативная splash-заставка Android с той же эмблемой.
- Сохранены импорт аудиофайлов и папок, поиск, фильтры, плейлисты и нижняя навигация.
- Версия приложения повышена до 0.1.1, Android `versionCode` — до 2 для установки обновления поверх предыдущей версии.

Для проверки: `npm ci`, `npm test`, `npx expo-doctor`. Для APK: `eas build --platform android --profile preview`.


## Обновление 0.1.2

- В правой части центрального баннера вместо DP установлен `foxsmusic-logo.png`; DP в верхней шапке сохранён.
- Импорт аудио теперь копирует выбранные файлы последовательно во внутреннее постоянное хранилище приложения. Временная копия Document Picker удаляется после успешного сохранения.
- Добавлено подключение папки `Music` через системный Android SAF-пикер. Пользователь выбирает папку и выдаёт доступ сам; FoxsMusic сохраняет URI разрешения и повторно сканирует выбранную папку при следующих запусках.
- Сканирование включает вложенные подпапки, ограничено глубиной 8 уровней и импортом до 250 новых файлов за один проход.
- Версия Android повышена до 0.1.2 (`versionCode` 3).

Приложение не сканирует весь накопитель скрытно: первый выбор папки и выдача доступа выполняются пользователем через системное окно Android.
