# FoxsMusic Mobile 0.2.0

## Улучшения библиотеки

- Сортировка треков: недавно добавленные, название, исполнитель.
- Фильтр источников: все папки, отдельная папка, отдельно импортированные файлы.
- Поиск учитывает имя исходной папки.
- Повторное сканирование уже подключённой папки Music без повторного открытия системного выбора папки.
- Версия Android повышена до 0.2.0, `versionCode` — до 5.

## Проверка

Запустить из папки `mobile`:

```bash
npm test
```

Для установки на телефон собрать preview APK через EAS:

```bash
eas build --platform android --profile preview
```
