# Отчёт об автоматических проверках FoxsMusic

Проверки выполнены на исходных файлах из предоставленного архива. Код приложений специально не переписывался при упаковке.

## Desktop

Команда: `npm test`

**Результат: успешно, 11 групп тестов пройдены.**

Проверены перемешивание и повтор, горячие клавиши, экран Now Playing, локализация RU/EN/DE, полноэкранный режим F11, IndexedDB, проверка резервных копий, умные плейлисты, дата добавления треков и выравнивание кнопок удаления/закрытия.

## Android

Команда: `cd mobile && npm test`

**Результат: успешно, 11 тестов пройдены, 0 ошибок.**

Проверены идентификатор Android-приложения, параметры фонового воспроизведения, конфигурация splash screen, наличие иконок/ресурсов, профиль EAS для APK и вспомогательные функции обработки аудиофайлов.

## Границы проверки

Это автоматические проверки кода и конфигурации. В этой среде не выполнялась полноценная сборка Electron-инсталлятора или Android APK и не проводился ручной тест на физическом телефоне. Перед публикацией рекомендуется отдельно запустить обе версии на целевых устройствах.
