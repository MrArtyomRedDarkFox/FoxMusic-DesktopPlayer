# FoxsMusic Desktop 1.3.24 — свой фон и сезон «День рождения»

## Что добавлено

### Собственная фоновая картинка
- В настройках профиля появился выбор изображения для фона приложения.
- Поддерживаются PNG, JPG/JPEG и WebP до 10 МБ.
- Выбранное изображение копируется в папку данных FoxsMusic (`userData/profile-backgrounds`), поэтому исходный файл можно переместить или переименовать.
- Настройка восстанавливается после перезапуска.
- Кнопка «Удалить картинку» удаляет сохранённую копию из данных приложения и возвращает стандартный фон. Исходный файл пользователя не удаляется.

### Сезон «День рождения»
- Добавлен в список сезонных режимов рядом с обычным, Хэллоуином и Новым годом.
- В центре баннера — праздничный торт с тремя зажжёнными свечами.
- По бокам плавно падают конфеты и конфетти; добавлено мягкое свечение.
- Добавлены локализованные надписи RU/EN/DE.
- Анимации отключаются при системной настройке `prefers-reduced-motion`.

## Как включить
1. Запустите FoxsMusic Desktop.
2. Откройте «Настройки» и раздел «Оформление профиля».
3. В поле «Фоновая картинка» нажмите «Выбрать картинку» и укажите PNG/JPG/WebP.
4. Чтобы вернуть стандартный фон, нажмите «Удалить картинку».
5. В выпадающем списке «Сезонный режим» выберите «День рождения».

Фоновая картинка и сезонный режим независимы: можно использовать собственный фон вместе с любым сезонным оформлением.
