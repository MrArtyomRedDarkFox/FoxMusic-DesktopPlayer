# FoxsMusic — стабилизация Android-плеера

В этой сборке сохранён полный проект Desktop Player + FoxsMusic Mobile. Компьютерный `app.js` не изменялся.

## Что изменено в мобильном плеере

- Зарезервирована постоянная высота области названия трека и исполнителя, чтобы длинные и короткие названия не сдвигали элементы управления.
- Область предпросмотра очереди сохраняет минимальную высоту пяти строк даже в конце очереди.
- Для строк очереди используются ключи по ID трека, а не по позиции в списке.
- Удалены дублирующие объявления стилей в итоговом `App.js`.
- В `mobile/package.json` и `mobile/package-lock.json` синхронизированы Expo `58.0.22` и Expo Audio `58.0.11`, как в коммите `505f173` репозитория.

## Проверки

Из папки `mobile`:

```powershell
npm.cmd test
```

Из корня проекта:

```powershell
npm.cmd test
```

После замены исходников на телефоне перезапустите Expo с очисткой кэша:

```powershell
cd mobile
npx.cmd expo start -c
```

Фикс layout покрыт тестами статической структуры. Финальное подтверждение отсутствия визуального скачка нужно сделать на Android-устройстве, переключая треки, включая последние позиции очереди.

### Результат локальной проверки исходников

- Mobile: `npm test` — 40/40 тестов пройдены.
- Desktop: `npm test` — завершился успешно.
- `mobile/App.js` прошёл разбор синтаксиса JavaScript/JSX.

Expo Doctor, Android APK/EAS build и визуальная проверка на телефоне в этой среде не запускались. Поэтому после распаковки нужно отдельно проверить переключение треков на Android.
