# FoxsMusic Desktop 1.3.26 — анимация дня рождения

- Пламя трёх свечей получило независимое естественное мерцание по механике New Year: мягкое изменение формы, яркости и направления.
- Добавлены внутренние световые сердцевины и маленькие искры, плавно поднимающиеся над свечами.
- Поле конфетти увеличено до 24 элементов. Каждая частица падает по непрерывной траектории, слегка покачивается и постепенно растворяется перед началом следующего цикла.
- Конфеты также получили более длинный цикл падения, боковой дрейф и плавное появление/исчезновение.
- При системном `prefers-reduced-motion` праздничная анимация продолжает работать, как в Halloween/New Year; отключить её можно штатным переключателем Effects в FoxsMusic.
- Версия Desktop: 1.3.26. Мобильный проект не изменялся.

Проверка: `npm test`.
